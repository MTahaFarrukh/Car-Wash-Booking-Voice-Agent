Sparkle Car Wash Voice Agent

Minimal test page for the Uplift AI Voice booking agent.

Before testing:
  1. Run python app.py in the project folder.
  2. Create the Uplift assistant using agents/uplift_assistant.json.
  3. Set the assistant to public in Uplift dashboard.
  4. For save_booking tool execution, use the React SDK pattern in agents/uplift_agent.md.
  5. Verify saved bookings: GET /bookings or check bookings.csv.
